# 游戏剧情档案馆 · Story Atlas

一个手机优先的《巫师 3》全剧透剧情档案网站：把故事路线、人物关系、选择后果、结局矩阵和两个 DLC 放在同一张可以展开的地图上。

## 本地运行

```bash
npm install
npm run dev
```

生产构建：

```bash
npm run build
```

## 内容结构

- `src/data.ts`：剧情、人物、关系、选择、结局、DLC 对照和通用分析方法。
- `src/App.tsx`：总览、剧情路线、人物关系、选择与结局、DLC、分析方法六个阅读面。
- `src/styles.css`：折页档案视觉系统，以及手机/桌面响应式布局。

## 后续扩展

新增游戏时，优先复用 `src/data.ts` 中的字段结构：

1. 核心问题与世界规则
2. 主线转折与重要支线
3. 人物动机与关系
4. 被延迟的选择与代价
5. 本体与 DLC 的主题变化
6. 结局矩阵

然后再把数据接入统一的导航和图表组件。
